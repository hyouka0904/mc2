# 原版遊戲說明書

[English](original-game.md) ｜ [回到 README](../../README.zh-TW.md)

這份說明書涵蓋單人遊戲：安裝、選單、戰役流程、整備和任務中的操作。聯機請看[區網對戰說明書](lan-skirmish.zh-TW.md)。

## 安裝與啟動

先到 [README](../../README.zh-TW.md) 下載對應平台的檔案。

| 平台 | 步驟 |
|---|---|
| **Windows** | 執行 `…-setup.exe`，照畫面安裝，之後從開始選單開啟 MechCommander 2。程式沒有數位簽章，SmartScreen 可能顯示警告：按「其他資訊」→「仍要執行」。免安裝版：解壓 zip 後執行 `mc2.exe`。 |
| **macOS** | 打開 `.dmg`，把「MechCommander 2」拖到「應用程式」後開啟。程式未經 Apple 公證，第一次會被擋下：到「系統設定」→「隱私權與安全性」按「強制打開」。 |
| **Linux** | AppImage：執行 `chmod +x MechCommander2-*.AppImage` 後開啟（需要 FUSE 2，套件名稱是 `libfuse2` 或 `libfuse2t64`）。壓縮檔：解壓後執行資料夾中的 `./mc2`。 |

更新版本時直接安裝新版即可，存檔和設定不會被刪除。

## 主選單

| 按鈕 | 用途 |
|---|---|
| **Campaign** | 開始新戰役，或繼續目前的戰役 |
| **Solo Mission** | 單獨挑戰已解鎖的任務，不影響戰役進度 |
| **Multiplayer** | 聯機，見[區網對戰說明書](lan-skirmish.zh-TW.md) |
| **Load Game** | 讀取存檔 |
| **Options** | 畫面、音效、操作方式、熱鍵設定 |
| **Encyclopedia** | 機甲、載具、武器、駕駛員的資料庫 |
| **Exit** | 離開遊戲 |

## 戰役流程

每一關都依序經過下列畫面，最後出擊：

1. **任務簡報**：任務目標、地圖和敵情。
2. **機甲庫（Mech Bay）**：選擇要出擊的機甲。用資源點數（RP）購買或賣出機甲；按 **MechLab** 可以替機甲更換武器和裝甲。改裝時要注意總重量、熱量和武器的位置限制。
3. **駕駛員**：替每台機甲指派駕駛員。駕駛員在任務中累積經驗，技能會成長；陣亡的駕駛員不會回來。
4. **出擊**：進入任務。

任務結束後會顯示結算：完成的目標、獲得的 RP、可以回收的敵方機甲和零件。

## 操作

### 滑鼠

預設操作方式（可以在 Options 切換回原版的單鍵操作）：

| 動作 | 效果 |
|---|---|
| 左鍵點單位 | 選取 |
| 左鍵拖曳 | 框選多個單位 |
| 右鍵點地面 | 移動到該處 |
| 右鍵點敵人 | 攻擊 |
| 按住 **Ctrl** 再右鍵 | 加入路徑點，依序移動 |

### 熱鍵

遊戲中按 **F1** 會顯示完整的熱鍵清單，熱鍵也可以在 Options 修改。以下是預設值。

**單位指令**

| 按鍵 | 指令 |
|---|---|
| **S**／**M**／**L** | 以短／中／長程距離攻擊 |
| **D** | 以最佳距離攻擊 |
| **C** | 原地開火（不移動） |
| **F** | 強制攻擊（可以攻擊建築或地面） |
| **G** | 護衛 |
| **H** | 固守位置：不移動，直到下達移動或佔領指令 |
| **J** | 跳躍（有跳躍噴射器的機甲） |
| 按住 **Space** | 跑步 |
| **W** | 節省彈藥 |
| **A** | 只用能量武器（節省彈藥） |
| 數字鍵盤 **2**／**5**／**8** | 瞄準腿部／手臂／頭部 |
| **Backspace** | 停止，取消目前的指令 |
| **Page Down**／**Page Up** | 關機（散熱）／開機 |
| **End** | 駕駛員彈射 |
| **V** | 特殊單位指令（例如維修車、回收車） |
| 數字鍵盤 **\***／**/** | 空襲／感測器探針（有可用的支援時） |
| **I** | 顯示選取單位的資訊 |

**選取與編隊**

| 按鍵 | 效果 |
|---|---|
| **Ctrl + 0–9** | 把選取的單位編成第 0–9 隊 |
| **0–9** | 選取該隊 |
| **Shift + 0–9** | 把該隊加入目前的選取 |
| **E** | 選取畫面上所有自己的單位 |
| **Shift + E** | 把畫面上的單位加入選取 |

**鏡頭與介面**

| 按鍵 | 效果 |
|---|---|
| 方向鍵 | 移動鏡頭 |
| **Shift + 方向鍵** | 旋轉、傾斜鏡頭 |
| **+**／**-** | 拉近／拉遠 |
| **Home** | 鏡頭回到選取的單位 |
| **F2**–**F5** | 預設鏡頭角度；**Ctrl + F2–F5** 把目前的鏡頭存進該位置 |
| **N** | 跳到下一個導航點 |
| **F9** | 顯示任務目標 |
| **Tab**／**Shift + Tab** | 切換介面分頁 |
| **\\** | 顯示或隱藏指北針 |
| **Esc** | 暫停並開啟選單（存檔、讀檔、選項、離開） |

## 存檔與設定

存檔和設定放在下列資料夾。解除安裝遊戲不會刪除它們。

| 系統 | 位置 |
|---|---|
| Windows | `%APPDATA%\MechCommander2\` |
| macOS | `~/Library/Application Support/MechCommander2/` |
| Linux | `~/.local/share/MechCommander2/` |

任務中按 **Esc** 可以快速存檔（Quick Save）和快速讀檔（Quick Load）。

## 命令列參數

| 參數 | 作用 |
|---|---|
| `-version` | 顯示版本後結束 |
| `-windowed` | 一律以視窗執行 |
| `-renderer gl` | 改用 OpenGL 繪圖（舊顯示卡或畫面異常時試試看） |
| `-mods <資料夾>` | 載入 Mod，見 [Mod 說明](../modding.zh-TW.md) |
| `-mission <名稱>` | 直接進入指定任務，例如 `-mission mc2_01` |

Windows 可以在捷徑的「目標」欄位後面加上參數；macOS 和 Linux 在終端機執行。

## 常見問題

| 狀況 | 處理方式 |
|---|---|
| 畫面全黑、閃退 | 加上 `-renderer gl` 啟動；更新顯示卡驅動程式 |
| 全螢幕顯示不正常 | 加上 `-windowed` 啟動，或在 Options 調整解析度 |
| 第一次開啟被系統擋下 | 見上方[安裝與啟動](#安裝與啟動)的 SmartScreen／Gatekeeper 說明 |
| 其他錯誤 | 到本專案的 [Issues](https://github.com/hyouka0904/mc2/issues) 回報，附上系統、版本（`-version`）和錯誤畫面 |

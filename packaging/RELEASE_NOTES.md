| Platform / 平台 | File / 檔案 |
|---|---|
| Windows 10+ (x64) | `*-windows-x64-setup.exe` (installer / 安裝程式) or `*-windows-x64.zip` (portable / 免安裝) |
| macOS 13+ (Apple Silicon) | `*-macos-arm64.dmg` |
| Linux x86_64 | `*-linux-x86_64.AppImage` or `*-linux-x86_64.tar.gz` |

The packages are not code-signed: Windows SmartScreen and macOS Gatekeeper ask once before the first start (see `README.txt` in the package). Checksums: `SHA256SUMS.txt`.
